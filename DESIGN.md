# DESIGN.md — визуальные правила garmonica

Единый гайд для вёрстки. При сомнении смотри `app/static/css/base/root.css` и существующие секции страницы услуги.

============================================================
1. ШРИФТЫ
============================================================

- Заголовки: `Montserrat` → `var(--font-headline)`
- Текст: `Manrope` → `var(--font-text)`
- Не подключать Inter / Roboto / system-ui как основной шрифт страницы

============================================================
2. ЗАГОЛОВКИ СЕКЦИЙ
============================================================

### H1 (hero страницы)

| Свойство | Значение |
|---|---|
| font-family | `var(--font-headline)` |
| font-size | `var(--font-size-h1)` ≈ 30–48px |
| font-weight | `var(--font-weight-h1)` = **600** |
| line-height | 1.15 |
| letter-spacing | -0.02em |

### H2 (заголовок секции)

| Свойство | Значение |
|---|---|
| font-family | `var(--font-headline)` |
| font-size | `var(--font-size-h2)` ≈ 28–40px |
| font-weight | `var(--font-weight-h2)` = **600** |
| line-height | 1.15 |
| letter-spacing | -0.02em |
| color | `var(--color-text-dark)` |

Запрещено для H1/H2 секций:

- `font-weight: 300` / `400` (выглядит «тонко» и ломает ритм)
- `var(--font-text)` вместо headline
- произвольный `clamp()` вместо `--font-size-h1` / `--font-size-h2`, если нет особой причины

Акцент внутри заголовка — через span и `var(--color-accent)`.

Классы-эталоны: `.service-diff__title`, `.service-price__title`, `.reviews__title`, `.section__title`.

### H3 и ниже — не использовать

**`h3` / `h4` / `h5` / `h6` на сайте не ставить**, пока пользователь явно и конкретно не попросил именно этот уровень.

Для имён в карточках, подзаголовков внутри секции, названий вкладок — обычный текст:

- `<p class="…__name">`, `<p class="…__title">`, `<span>`
- визуальный вес через CSS (`font-family`, `font-weight`, `font-size`), не через новый уровень заголовка

Иерархия страницы:

1. один `h1` (hero)
2. `h2` у секций
3. дальше — без heading-тегов, пока нет прямой просьбы

============================================================
3. ЦВЕТА
============================================================

Источник правды: `:root` в `app/static/css/base/root.css`.

| Роль | Переменная | Пример |
|---|---|---|
| Основной акцент (синий) | `--color-accent` | `#5b9bd5` |
| Акцент hover | `--color-accent-hover` | `#4a89c3` |
| Акцент мягкий / фон | `--color-accent-light` | `#e8f4fb` |
| Тёплый CTA | `--color-warm` | `#fdb863` |
| Текст | `--color-text-dark` | `#1a2a3a` |
| Приглушённый текст | `--color-text-muted` | `#5a6b7c` |
| Фон-вырезка | `--color-cutout` | `#f5f9fc` |
| Бордер | `--color-border` | `#d7e6f2` |

Правила:

- Кнопки и активные табы — `--color-accent`
- Не вводить новый «фирменный» цвет без переменной в `:root`
- Не красить текст акцентом целыми абзацами — только акценты в заголовках, ссылках, иконках, CTA

============================================================
4. КНОПКИ
============================================================

Базовый класс: `.button` (`app/static/css/components/button.css`).

### Цвет — всегда акцент

**Все action-кнопки по умолчанию — `.button--primary`** (заливка `--color-accent`).

Запрещено для обычных CTA в секциях:

- `.button--outline` / `.button--ghost` как основная кнопка блока («Все специалисты», «Смотреть ещё», ссылки-кнопки)
- Серые / нейтральные «контурные» кнопки вместо акцента
- Новые модификаторы цвета без записи в дизайн-систему

Исключение: `.button--warm` — только срочный телефонный CTA в hero / шапке, когда явно нужен тёплый акцент (`tel:`). Не использовать warm для обычных ссылок и вторичных кнопок.

Модификаторы:

- `.button--primary` — **дефолт для всех CTA**
- `.button--warm` — только urgent `tel:` CTA
- `.button--outline` / `.button--ghost` — не для основных кнопок секций (избегать)

### Иконки в кнопках — обязательно

У каждой кнопки с действием желательна иконка слева (или справа для «далее»):

```html
<a class="button button--primary" href="/vrachi/">
  <img class="button__icon" src="/assets/icons/users.svg" alt="" width="16" height="16" decoding="async">
  Все специалисты
</a>
```

Правила:

- Класс иконки: `.button__icon`
- Размер в кнопке: **16×16** (`width`/`height` + CSS 1rem)
- `alt=""` (декоративная)
- На primary / warm иконка белеет через filter в `icons.css`
- Не делать кнопку без иконки, если рядом в секции у соседних CTA иконки уже есть

============================================================
5. ИКОНКИ PHOSPHOR
============================================================

Каталог: `app/static/icons/phosphor/`

Использование:

- UI-иконки в карточках, списках преимуществ, прайсе, оплате, diff-блоках — **Phosphor**
- Фавиконки площадок отзывов / мессенджеров — отдельные файлы в `icons/reviews/`, не Phosphor
- Размер в карточках/фичах: обычно **22×22**
- Размер в кнопках / мелком UI: **16×16**
- Монохромные SVG через `<img>` тонируются фильтром из `icons.css` (синий tint)
- Новый Phosphor-SVG класть в `app/static/icons/phosphor/` и подключать селектор tint в `icons.css`, если нужен тот же цвет

Пример:

```html
<img src="/assets/icons/phosphor/stethoscope.svg" alt="" width="22" height="22" decoding="async">
```

============================================================
6. СЕКЦИИ И РИТМ
============================================================

- Ширина контента: `var(--page-shell-width)`
- Один H1 на страницу
- H2 секций — один на секцию, без скачков h2 → h5
- Mobile-first, контрольные ширины: 320 / 375 / 430 / 768 / 1024 / 1280 / 1440

### Отступы между блоками (обязательно)

Единый вертикальный ритм: `var(--section-fade)`  
`clamp(2.25rem, 4.5vw, 3.5rem)` ≈ **36–56px**

На **странице услуги** соседние блоки идут так:

```css
.block {
  width: var(--page-shell-width);
  margin: 0 auto var(--section-fade); /* только снизу */
  padding-block: 0;
}
```

Эталоны: `.service-price`, `.service-payment`, `.service-diff`, `.reviews--service`.

Запрещено:

- `padding-block: var(--section-fade)` **и** `margin-bottom: var(--section-fade)` у соседних блоков подряд (получается двойной зазор)
- Произвольные `margin-top: 4rem` / `padding-top: 80px` у секций
- Разный ритм у соседних секций одной страницы

На главной допустим `padding-block: var(--section-fade)` у секции, если у неё нет нижнего margin у предыдущего блока с тем же `--section-fade`.

============================================================
7. КАРТОЧКИ И ДЕКОР
============================================================

- Не плодить «карточки ради карточек» в hero
- Радиусы только из переменных: `--radius-sm|md|lg|xl|button`
- Тени — `--shadow-soft`, без многослойного glow
- BEM: `.block`, `.block__element`, `.block--modifier`
- JS-хуки — через `data-*`, не через чисто стилистические классы

============================================================
8. ИЗОБРАЖЕНИЯ
============================================================

- Всегда: `alt`, `width`, `height`
- Ниже первого экрана: `loading="lazy"` + `decoding="async"`
- LCP / hero: без lazy, при необходимости `fetchpriority="high"`
- Предпочтительно WebP

============================================================
9. ЧЕКЛИСТ ПЕРЕД СДАЧЕЙ БЛОКА
============================================================

- [ ] H2 секции: Montserrat, weight 600, `var(--font-size-h2)`
- [ ] Нет `h3`–`h6` (если пользователь сам не просил)
- [ ] Акцентные цвета только из `:root`
- [ ] CTA-кнопки: `.button--primary` (не outline/ghost)
- [ ] CTA-кнопки с `.button__icon`
- [ ] UI-иконки из Phosphor (кроме брендовых фавиконов)
- [ ] Новый селектор иконки добавлен в tint `icons.css`, если нужен цвет
- [ ] Нет inline CSS / inline JS
- [ ] Cache-bust `?v=` в `base.html` обновлён после правок CSS
